# Merwin DMello — Portfolio Website

A responsive, multi-page static portfolio created from the supplied October 2026 resume and styled using the provided navy/blue CSS direction.

## Pages
- `index.html` — Home / profile overview
- `about.html` — About and approach
- `projects.html` — Selected project case studies
- `experience.html` — Career timeline, education and speaking
- `skills.html` — Skills and certifications
- `contact.html` — Contact links

## Preview locally
Open `index.html` in a browser. No build step or JavaScript dependencies are required.

## Publish
Upload the folder contents to GitHub Pages, Cloudflare Pages, or another static host. Keep all HTML pages and `styles.css` in the same directory.

## Before publishing
Review the contact details and LinkedIn URL. Consider adding a downloadable resume PDF and project diagrams/screenshots if you want richer case studies.
